LocalPilot is a Python-based computer assistant designed to make managing a computer easier through simple commands.  
The current version is a command-line application that can display system information, CPU usage, RAM usage, storage information, local IP address, and ping hosts on the network.  
Over time, LocalPilot will expand to include file browsing, directory searching, file operations, automation, natural-language commands, remote machine management, scheduling, monitoring, and potentially a web interface.  
This project is being built as part of Hack Club Terra, with the goal of learning Python and software engineering by building a real application from the ground up.
