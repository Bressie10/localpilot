# localpilot
LocalPilot is a Python-based computer assistant built to make managing a computer easier through simple commands.
The project will start as a command-line application for viewing system information, browsing files, searching directories, and performing basic file operations.
Over time, LocalPilot will grow to include automation, natural-language commands, remote machine management, scheduling, monitoring, and potentially a web interface.
This project is being built as part of Hack Club Terra, with the goal of learning Python and software engineering by building a real application from the ground up.
